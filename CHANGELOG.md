# Changelog

All notable changes to the Exismic platform will be documented in this file.

---

## [1.6.5] - September 2026

### What's New
A cleaner look for signing in and creating an account, clearer icons across the platform, interactive playground upgrades, and smoother mobile navigation.

- **Fresh Sign-In & Sign-Up Experience**: Upgraded the login and account creation screen with a modern frosted look, glowing focus borders, and clean, clear field labels.
- **Interactive Age Confirmation**: Replaced the basic browser checkbox with an easy-to-tap confirmation card featuring a smooth checkmark and shield badge.
- **Cleaner, Meaningful Icons**: Replaced decorative sparkle symbols across the site with clear, purposeful icons — like a Play icon for testing tools live and Studio Layers for creative platforms.
- **Upgraded Live Playground**: Improved tool icons and tab navigation so you can test image generation, background removal, and voice splitting directly from the homepage.
- **Mobile Button & Text Polish**: Fixed button text wrapping on phones so quick sign-in tags and buttons stay neatly aligned and readable on smaller screens.
- **Simple & Secure Account Recovery**: Streamlined password reset and account verification screens with clearer guidance and quick copy helpers.

## [1.6.0] - September 2026

### The Sparks Economy & Studio Cockpit
- **Exismic Sparks Rewards**: A brand new way to earn Sparks through daily and weekly tasks, unlock special avatar frames, glowing names, insignia badges, and streak shields.
- **Executive Studio Cockpit**: Redesigned dashboard with a fast tool launchpad, personalized activity vitals, favorites workstations, and smart tool recommendations.
- **Streak Freeze & Milestone Rewards**: Equip shields to protect your daily streaks against missed days and unlock special bonus rewards.
- **Streamlined Tool Headers**: Modernized headers and controls across all tools with improved layout and custom tool icons.
- **Exismic Cloud Drive & Tool Pipelines**: Centralized file storage with easy shortcuts to pass created art directly between tools.
- **Watermark-Free & Speed Boost**: Clean, unbranded image exports across all accounts and faster workspace loading.

## [1.5.0] - September 2026

### September Platform & Feature Release
- **Daily & Weekly Quests**: Complete rotating creative tasks and try new tools to earn rewards and keep your activity streaks going.
